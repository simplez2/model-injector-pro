# 使用指南

## 运行要求

- Chrome、Edge 或其他支持 Manifest V3 的 Chromium 浏览器。
- 可以正常访问受支持的 ChatGPT 网页。
- 使用本仓库源码时，需要完整保留 `extension/` 内的运行文件。

本项目是独立兼容工具，与 OpenAI 无隶属、授权、背书或赞助关系。它不会提供原本无权使用的模型或功能。

## 安装源码版本

1. 下载仓库并解压，或使用 Git 克隆。
2. 打开扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 开启开发者模式。
4. 点击“加载已解压的扩展程序”。
5. 选择 `extension/` 目录，而不是仓库根目录。
6. 打开或刷新 `https://chatgpt.com/`。

页面上出现原创轨道图标后，点击即可打开面板。若图标没有出现，先确认扩展已启用并刷新页面。

## 安装 Release ZIP

1. 从仓库 Release 下载 `model-injector-pro-v<version>.zip`。
2. 将 ZIP 解压到一个固定目录。
3. 在扩展管理页加载解压后的目录。

浏览器不会直接加载 ZIP。移动或删除解压目录后，开发者模式扩展也会失效。

## 基础使用

1. 点击悬浮图标打开面板。
2. 选择默认、预设、接口发现或自定义模型。
3. 对支持的模型选择 reasoning effort。
4. 打开启用开关。
5. 新建或继续会话，观察诊断状态。

页面发送请求时，扩展只会在命中的兼容请求上尝试调整相关字段。服务端可以忽略、回退或拒绝这些字段；这不代表扩展能够绕过账号权限。

## Token 显示

扩展在本地读取页面可见的会话文本，并通过随包的 `o200k_base` tokenizer 计算上下文规模。显示值用于容量判断，不应作为账单、服务端精确计数或硬性上下文边界的唯一依据。

## 设置与本地数据

语言、强调色、面板位置、模型选择、最近模型和调试开关保存在目标站点的 `localStorage` 中。它们不会同步到项目维护者控制的服务器。

若要只清除本扩展的本地状态，可在目标站点 DevTools Console 中执行：

```js
Object.keys(localStorage)
  .filter((key) => key.startsWith('cgpt_v12_'))
  .forEach((key) => localStorage.removeItem(key));
location.reload();
```

也可以在浏览器设置中清除目标站点数据，但那会同时退出登录并删除该站点的其他本地状态。

## 调试与导出

调试模式默认关闭。只在排查问题时临时开启，并在完成后关闭。诊断记录可能包含：

- 模型标识与 reasoning effort。
- 请求路径、时间和改写前后摘要。
- 页面发现的模型或 Workspace Agent 元数据。
- 错误信息与响应模型标识。

导出文件发送给他人前必须人工检查和脱敏。不要分享 Cookie、Authorization 头、账号标识、会话正文、内部链接或可用于访问账号的任何值。更详细的说明见 [PRIVACY.md](PRIVACY.md)。

## 更新

源码安装：拉取新代码后，在扩展管理页点击重新加载，再刷新目标网页。

Release 安装：解压新版本覆盖旧目录，或加载到新目录；随后在扩展管理页重新加载。更新前可记录当前设置，但不要把浏览器存储或账号数据提交到仓库。

## 常见问题

### 悬浮图标没有出现

- 确认加载的是 `extension/` 目录。
- 确认当前网址在 manifest 支持范围内。
- 在扩展管理页查看是否有加载错误。
- 刷新页面；必要时关闭其他会修改同一页面的扩展后再测试。

### 模型选择没有生效

- 确认主开关已启用。
- 确认 model slug 拼写正确。
- 尝试新建会话，避免旧会话状态覆盖选择。
- 检查账号是否本来就有对应功能权限。
- 目标网站更新后，内部请求格式可能变化；请在移除敏感信息后报告兼容问题。

### 页面功能异常或请求失败

先关闭扩展主开关并刷新。如果异常消失，请记录最小复现步骤、浏览器版本、扩展版本和脱敏后的控制台错误。不要直接公开完整抓包。

### Token 数值与服务端不一致

页面可见文本、隐藏系统消息、附件处理、服务端模板和 tokenizer 版本都可能造成差异。该数值是本地辅助指标，不是服务端权威计数。

## 卸载

在浏览器扩展管理页移除扩展。由于偏好存储在目标站点页面的 `localStorage`，仅移除扩展不一定清除这些键；如有需要，再按“设置与本地数据”一节清除。
