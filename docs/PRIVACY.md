# 隐私说明

生效日期：2026-07-30

Model Injector Pro 是独立、无后端的浏览器扩展，与 OpenAI 无隶属、授权、背书或赞助关系。本说明描述公开源码版本的默认行为；自行修改配置或代码可能改变这些行为。

## 核心结论

- 项目不提供维护者控制的遥测、分析或账号收集服务。
- 扩展不会把会话正文发送给项目维护者。
- 扩展会在目标网页本地读取必要的会话 DOM 和相关网络数据，以实现 token 统计、模型发现、请求调整和诊断。
- 调试导出可能包含敏感元数据，必须在分享前人工脱敏。

## 本地处理的数据

扩展可能在当前目标网页内处理：

- 用户选择的模型、reasoning effort、语言、颜色和面板位置。
- 最近模型、自定义模型及同源接口发现的模型或 Agent 元数据。
- 页面可见的会话文本，用于本地 tokenizer 计算。
- 与支持路径有关的请求方法、路径、payload 字段和响应模型标识。
- 为诊断兼容性而生成的错误、时间和改写摘要。
- 页面现有模型目录请求中的有限请求头快照，包括 `authorization`、`chatgpt-account-id`、语言、客户端版本和路由头；该快照仅用于同源模型目录刷新。

上述请求头快照只保存在当前页面内存中，不写入 `localStorage`、抓包日志或诊断导出，也不会发送到项目维护者控制的域名。扩展不将 Cookie 或完整 Authorization 值写入持久诊断记录。现有网站凭据仍由浏览器和目标网站管理，并会按目标网站自身流程用于同源请求。

## 存储

偏好、接口发现结果和诊断面板开关使用 `cgpt_v12_` 前缀保存在目标站点的 `localStorage` 中。请求头快照和抓包日志不写入该存储。由于运行在页面主世界，同源页面脚本能够访问相同存储和页面属性；请不要把任何扩展状态当作秘密保险库。

调试模式默认关闭。关闭调试后，公开版本应停止记录并清理抓包日志。若主动导出诊断，浏览器会把文件保存到用户选择或默认的下载位置，之后的保存、传输和删除由用户负责。

## 网络传输

扩展会修改或读取目标网页本来就会访问的同源接口。用户刷新模型目录时，它会主动请求目标网站的同源模型路径，并可能复用上一节所列的有限请求头快照；请求目标始终由当前站点 origin 解析，不会把这些凭据转发到第三方或项目方域名。数据会受目标网站自己的隐私政策、账号设置和基础设施约束。

公开默认配置没有项目方 API、遥测地址或远程配置服务。Sponsor 模块默认关闭；若使用者自行启用，只有点击链接时才会导航到所配置的网站。

## 权限

浏览器 host permissions 仅用于 manifest 声明的兼容站点。公开版本不申请浏览历史、下载内容、剪贴板、地理位置、摄像头、麦克风或后台常驻服务权限。

目标网站和浏览器更新可能改变权限解释或页面运行行为。安装前应查看当前 `extension/manifest.json`，它是实际权限的权威来源。

## 数据保留与删除

本地状态会保留到用户清除站点数据、执行针对前缀的清理代码，或浏览器自身删除数据为止。只清理本扩展键值的方法见 [USAGE.md](USAGE.md)。卸载扩展不保证目标站点 `localStorage` 同时被清空。

维护者没有项目后端，因此无法远程查看、导出或删除用户浏览器里的这些数据。

## 分享诊断时的注意事项

在 Issue、聊天、邮件或其他渠道发送诊断前，至少删除：

- Cookie、Authorization 或其他请求凭据。
- 账号 ID、电子邮件、组织或 Workspace 标识。
- 会话 ID、完整 URL query、内部 Agent 链接。
- 提示词、回复正文、附件名和私人文件路径。
- 能关联个人设备、公司、网络或账号的错误上下文。

如报告安全漏洞，请使用 GitHub Security Advisory 私下提交，并遵循仓库根目录的 [SECURITY.md](../SECURITY.md)。

## 第三方

目标网站、浏览器、GitHub 和用户自行配置的外部链接是独立第三方，适用各自的隐私条款。本仓库的 tokenizer 在本地执行；其软件归属见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 变更

隐私相关代码、默认配置或权限发生实质变化时，应同步更新本文件并在版本记录中说明。以用户实际安装版本内的文档和源码为准。
